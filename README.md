# 东秦杀：点名册 · 可玩版

直接双击 **index.html** 即可开始游戏（纯静态、无构建、无需联网、file:// 协议可直接运行）。

## 文件结构

```
东秦杀/
├─ index.html          入口（双击即玩）
├─ css/style.css       全部样式
├─ js/data.js          数据层：160 张牌 / 20 名角色 / 身份配置 / 每张牌的详细说明
├─ js/fx.js            音效（Web Audio 合成）+ 特效（出牌特写/飘字/震动/翻牌/阵亡）+ 长按详情
├─ js/engine.js        规则引擎：回合流程 / 距离 / 装备 / 判定 / 濒死 / 胜负 / 40 技能
├─ js/ai.js            AI 决策：出牌评分 + 响应判断 + 简易身份推断（行为记忆）
├─ js/ui.js            渲染与人类交互（选牌、选目标、判定动画、结算界面）
├─ js/main.js          启动、选角、开局编排
└─ 东秦杀-规则书.md    完整规则书 v1.0（本实现的依据）
```

## 已实现的规则（对照规则书）

| 模块 | 实现内容 |
|---|---|
| 身份 | 4–8 人配置表；院长体力上限 +1、身份公开、先手、起手 5 张；其余身份隐藏，死亡时揭示 |
| 胜负 | 院方胜（学生+卧底全灭且院长存活）/ 学生胜（院长死亡且卧底非唯一存活）/ 卧底胜（院长死亡时唯一存活）/ 平局 |
| 回合 | 回合开始 → 查考勤 → 摸牌 → 出牌 → 弃牌 → 结束；跳过阶段、额外回合机制 |
| 距离 | 座位间隔 + ±1 坐骑 + 虎爷【震慑】+ 鸟爷【观鸟】；数学郭【极限】最终值锁定为 1；最小为 1 |
| 攻击范围 | 无武器 = 1，由武器牌数值决定 |
| 判定 | 抽签牌 = 牌堆顶；手机没电（非♥）/ 饭卡没钱（非♣）/ 论文查重（♠2-9，15.6%）/ 校园卡（红色 49.4%）；通知栏后进先出；论文查重传递 |
| 装备 | 全部 25 张：点名册（不限点名）、激光笔、教鞭、试卷（无视防具）、红笔（穿透代课）、戒尺（连击）、粉笔、黑板擦（三目标）、监控摄像头、红头文件、电风扇（转化火杀）、校园卡、学生证、医保卡、雨衣、四匹+1坐骑、三匹-1坐骑 |
| 基本牌 | 上课点名/公开处刑（火）/雷同警告（雷）/代课/请假条/红牛（增益+濒死回复） |
| 事件牌 | 全部 20 种，含拼点（京爷）、点名接力（拒绝即失去武器）、小组连坐（横置+属性伤害传导）、小组作业（亮牌轮流选） |
| 响应链 | 代课 → 王磊【贬低】无效 → 红笔穿透 / 戒尺连击；辅导员签字三层对抗链 |
| 濒死 | 本人第 0 步优先自救 → 从当前回合角色起按座位顺序求援 → 追加窗口 → 未救回则死亡；宋美丽【鼓励】可插入救援 |
| 死亡奖惩 | 击杀学生摸 3 张；院长杀教务弃光所有牌；击杀卧底无奖惩（可选房规） |
| 技能 | 20 名角色 40 个技能全部实现（锁定技 / 主动技 / 触发技） |
| 手牌上限 | = 当前体力；波比【体能】+1 |

## 视听反馈

| 功能 | 说明 |
|---|---|
| **中央出牌区** | 任何人使用任何一张牌，都会排进中央出牌区：卡牌缩略图 + `谁` 使用 + 牌名 + 点数花色 + 效果 + 作用对象；后续响应牌以缩进小卡追加（`响应 · 抵消` / `无效化` / `视为使用`），**整条连锁结束才清空**；顶栏 `▶ 自动清空 / ⏸ 点击清空` 可切换 |
| 响应提示条 | 打出"代课 / 辅导员签字"等响应牌时，中央弹出轻量提示条：`王磊 打出 ♠2 代课　抵消`，不遮挡桌面 |
| 音效 | 全部用 Web Audio 实时合成（**不需要任何音频文件**）：出牌、点名、代课、伤害、回复、查考勤翻牌、装备、技能、阵亡、回合开始、胜负各有独立音色；顶栏 🔊 可静音（记忆在 localStorage） |
| 飘字与震动 | 受伤飘红色数字并按伤害量震动（≥2 点强震）、回复飘绿字、≥3 点伤害全屏红闪 |
| 查考勤 | 中央翻牌动画，红黑配色 + 音效 |
| 阵亡 | 全屏暗场 + 身份揭示卡 |
| 回合 / 技能 | 回合开始横幅（自己是"轮到你行动"）、技能名在角色面板上弹出 |
| **长按卡牌** | 手牌、装备区、通知栏、弹窗里的牌，长按 0.4 秒（或右键）→ 显示完整牌面：类型 / 目标 / 距离 / 效果 / 限制 / 结算顺序 |
| **长按角色** | 任意角色面板长按 → 显示角色详情：称号、体力、手牌上限、两个技能的完整文字、装备、通知栏、状态标记、与你的距离 |

## 桌面表现

| 项目 | 说明 |
|---|---|
| **横向座位队列** | 所有角色（**包括你自己**）按座位顺序从左到右排成一行，自动换行、自动等宽；你自己的面板用金色边框与顶边标出 |
| 距离直观 | 每名角色面板带 **距你 N** 标签；你的回合还会标出 **可点名 / 范围外**（按你当前武器的攻击范围） |
| **屏幕中央出牌区** | 棋盘正中的空白区就是出牌区：**一次结算连锁中的所有牌都排在这里**——主牌（含牌名 / 点数花色 / 效果 / 作用对象）+ 缩进的后续响应牌（代课"响应·抵消"、辅导员签字"无效化"、冲锋/波比跳/校园卡"视为使用"…）；**整条连锁结束后才清空**，然后开始下一张牌 |
| 出局者 | 死亡角色移出座位圈，缩小灰置在左下角 —— 他们**不再占座位、不参与距离计算**（与规则一致） |
| **通知栏可视化** | 延时类事件牌（手机没电 / 饭卡没钱 / 论文查重）以**小卡形式贴在角色面板上**，显示点数与花色、牌名；**最先结算的那张有紫色呼吸光**；可长按查看完整效果 |
| 距离实时更新 | 装备 ±1 坐骑、角色死亡改变座位圈后，全场面板与距离标签立即重算 |

## 角色唯一性

- **你可以多选一**：候选数由"你的选角候选"决定（3 / 5 / 2 / 8 张），只要求给每位电脑至少留 1 张武将，不再按人数硬性压缩；
- 你选定后，**没选走的那几张候选回归武将池**，电脑再从剩下的武将里按强度评分挑选；
- 电脑之间也互不重复，另有一层兜底校验，若仍检测到重复会立即替换并在日志告警；
- 选角界面会显示"你从 N 名武将中选 1 名；其余 X 名电脑会从剩下的 M 名里挑选"；
- 自检包含"当前对局角色不重复"断言。

## 修复记录

| 问题 | 原因 | 修复 |
|---|---|---|
| **点击装备牌提示"没有合法目标"、装备不上** | 装备牌在数据层只有 `type:'equip'`、缺 `kind` 字段，而 UI 与引擎都用 `meta.kind === 'equip'` 判断，永不成立 → UI 走到目标选择（合法目标为空）、引擎 `useCard` 也匹配不到装备分支会把牌直接丢进弃牌堆 | 数据层为全部装备牌统一补 `kind:'equip'`；自检新增"25 张装备牌均可正常装备""所有牌名都有 kind 字段"两条断言防回归 |
| 【试卷】无视防具判定在目标身上 | 判断写成了检查目标的武器 | 改为按**使用者**判定，并贯通到伤害结算（医保卡封顶、雨衣火焰 +1 一并失效） |
| 【校园卡】判定失败后无法用手牌代课 | 判定失败即关闭响应窗口 | 判定失败后重新询问同一角色（不再提供校园卡选项） |
| 【电风扇】【粉笔】绕过点名类牌次数上限 | 转化结算未校验 `usedAttackCardThisPhase` | 转化入口与结算处均加上限校验 |
| 同一局出现重复角色 | "每人 N 选 1"未限制总量，人多时角色池被抽干，后续座位回退到同一角色 | 候选数自动收敛为 `总角色数 ÷ 人数`；AI 只从未被选走的角色中挑；外加兜底替换与日志告警 |
| 面板/日志出现 `undefined` | 玩家对象缺 `name` 属性（名字在 `char.name`） | 以 getter 形式提供 `p.name` |

## 节奏（默认放慢，强调"看得清"）

顶栏 **`节奏：标准`** 按钮可在 标准(1.35×) → 很慢(1.9×) → 快(0.6×) → 极速(0.15×) 之间切换，**所有停顿与动画同比例缩放**。

默认节奏下每个环节的停顿：

| 环节 | 停顿 | 可见反馈 |
|---|---|---|
| 电脑玩家行动前 | 0.76 秒 | 面板右下角出现脉动的 **思考中…** |
| 出牌结算 | 每张 0.84 秒，整条连锁结束后再停 1.1 秒才清空 | 中央出牌区按顺序堆叠（牌名/点数/效果/作用对象） |
| 摸牌 | 0.4 秒 | 面板飘出 **+2 张** |
| 弃牌 | 0.35 秒 | 面板飘出 **弃 2 张** |
| 伤害 | 0.7 秒 | 飘伤害数字 + 面板震动（≥2 点强震） |
| 回复 | 0.5 秒 | 飘绿字 |
| 查考勤 | 1.2 秒 | 中央翻牌动画（切换为"点击清空"时改为等你点击） |
| 阶段切换 | 每阶段 0.35 秒 | 顶栏阶段名变化 |
| 回合之间 | 0.57 秒 | 回合横幅（轮到你时额外提示） |

电脑之间互相出牌时同样会停下来等你看——不会因为"只是 AI 在打"就一闪而过。

## 规则自检（验证装备是否生效）

游戏内点顶栏 **规则 → 运行自检**（或控制台执行 `runSelfTest()`），会自动校验 **30 项**并弹出报告：

- 牌堆构成：160 / 基本 85 / 事件 50（非延时 42 + 延时 8）/ 装备 25、点名册 2 张、坐骑 7 张
- 11 把武器的栏位与攻击距离、4 件防具、+1 / −1 坐骑标注
- 距离计算：基础距离、+1 坐骑、−1 坐骑、虎爷【震慑】、鸟爷【观鸟】、数学郭【极限】覆盖修正
- 防具免疫：学生证（黑色点名）/ 雨衣（点名、群伤、火焰 +1）/ 试卷无视防具 / 对照组
- 点名册解除点名次数上限、且不解除公开处刑限制、且仍受【吹牛】禁用
- 攻击范围取武器值、手牌上限 = 体力、波比【体能】+1
- 角色库：20 名、每人 ≤2 技能、无阵营字段、性别表覆盖

自检会临时构造测试角色并**跑完自动还原**，不影响正在进行的一局。

## 可选规则开关（开始界面）

- **保护轮**：第一圈内任何角色体力不会降到 1 以下（新手推荐）。
- **AI 接管其他玩家**：关闭后进入**热座模式**，每个座位都由玩家操作（左上角会显示"「X」的决策"）。
- 界面内 **规则** 按钮可随时查看速查表；**动画** 按钮可切换 正常/快速/极速/慢速。

## 已知简化（不影响正常对局）

1. **改判**：基础牌堆与基础角色没有改判来源，引擎未接入改判窗口（扩展时可在 `judgePhase` 的抽签牌翻开处插入）。
2. **断网标记**：作为可选规则（牌堆重洗时触发）保留在引擎中，默认关闭。
3. **AI 决策**：启发式评分 + 行为记忆（谁打过院长、谁救过人），不做完整贝叶斯身份推断；困难难度所需的 MCTS 见规则书 13.3。
4. **UI 交互**：目标选择使用弹窗而非拖拽；"可发动的触发技"会自动弹窗询问，不会遗漏。
5. **4 人局补偿**：学生额外 +1 张起手牌（规则书 9.5）。

## 快速验证清单

开局后按顺序检查这几项即可确认引擎正常：
1. 院长身份公开、体力比角色牌多 1、先行动、起手 5 张；
2. 出牌阶段点手牌 → 弹窗选目标 → 对方弹"是否打出代课"；
3. 点名命中后体力条减少，日志出现"受到 X 点普通伤害"；
4. 体力归零时弹出自救询问，救回后继续；
5. 有人死亡时翻开身份牌并结算奖惩（杀学生摸 3 张）；
6. 院长死亡立即结算胜负并显示身份揭示墙。
